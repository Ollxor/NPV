# Get ready before our session

To make the most of our hour together, please get **Claude Code** working on your
computer **before** the call. This takes about 20–30 minutes and needs no
technical skill. If you get stuck, message Olle — we'll sort it before we start,
and we'll also help each other in the meeting. Nobody gets left behind.

---

## 1. Create three accounts

| # | Account | Where | Notes |
|---|---------|-------|-------|
| 1 | **GitHub** | [github.com](https://github.com) | Free. This is where your system lives. |
| 2 | **Anthropic (API key + credit)** | [console.anthropic.com](https://console.anthropic.com) | Add **~€10–20** of credit under Billing, then create a key at [platform.claude.com/settings/keys](https://platform.claude.com/settings/keys) → **Create Key**. This powers both building and running. |
| 3 | **Claude Code** | [claude.ai/code](https://claude.ai/code) | The tool that builds it for you. Use the **desktop app** (no terminal needed). |

> **Important:** Claude Code requires a paid Claude plan **or** an Anthropic API
> key — the *free* Claude chat plan does **not** include it. The good news: the
> API key from account 2 can power Claude Code directly (pay-as-you-go), so you
> don't need a separate subscription. If you already have Claude Pro or Max, you
> can sign in with that instead.

## 2. Install Claude Code

Use the **desktop app** — no terminal required.

- **Mac:** [download the app](https://claude.ai/code), open it, and sign in with
  your Anthropic account (account 2 above).
- **Windows:** [download the app](https://claude.ai/code), install it, and sign
  in with your Anthropic account (account 2 above).

Official, always-current setup guide: <https://code.claude.com/docs/en/setup>

## 3. The readiness test (please do this!)

This is the single most useful thing you can do beforehand. It proves the whole
chain works — install, login, **and** the GitHub connection that trips people up.

1. Open Claude Code.
2. Ask it, in plain words:
   > *"Create a small test file and push it to a new repository on my GitHub called `npv-test`."*
3. When it asks permission to run commands, click **allow** — that's normal and
   safe, not a virus warning.
4. If a new `npv-test` repo shows up on your GitHub account, **you're ready.** 🎉

If it can't push, it's almost always the GitHub sign-in — or Git isn't installed
yet. On Mac, accept the "command line developer tools" prompt if it appears; on
Windows, install [Git for Windows](https://git-scm.com/downloads/win). Still
stuck? Message Olle and we'll fix it before the call rather than during it.

## If you can't get set up — a no-install option

You can still take full part. Either we help you live in the meeting, or you skip
Claude Code entirely and **fork the project in your browser**, editing a couple
of settings in GitHub's web editor — no installs, no terminal. It's less elegant,
but it gets you to a working feed with nothing on your computer.
