# For partner organisations

Welcome! These documents help Nordic and Baltic associations set up their own
automated research-and-news feed, modeled on NPV's system.

- **[SETUP.md](SETUP.md)** — get Claude Code ready on your computer before our
  session (accounts, install, and a quick readiness test).
- **[BUILD-INSTRUCTION.md](BUILD-INSTRUCTION.md)** — the instruction you paste
  into Claude Code; it interviews you and builds your own version.

See a live example — NPV's multilingual feed:
**<https://ollxor.github.io/NPV/>**

Questions? Reach out to Olle.
